# Prisma-MakeUp
Estado: Em desenvolvimento

## Contextualização
- Essa aplicação foi feita para o trabalho integrado da parte técnica no 3° ano do IFSULDEMINAS - Campus Passos. O trabalho consiste
em criar uma empresa do zero, incluindo planejamento empreendedor, sistema e site.
- Prisma MakeUp é uma empresa de maquiagem e ensino, com foco na acessibilidade e levar a maquiagem a todos.

## O que faz 

### Site
- Apresentar a equipe e a empresa
- Catalogo de produtos autorais e venda desses produtos
- Catálogo de cursos com acesso pelo Patreon
- ChatBot que instrui uma maquiagem para um evento
  
### Sistema
- Funcionalidades CRUD: Criar produtos e cursos; Analisar o banco com uma lista de itens(tabela de usuarios, produtos, cursos e pedidos);
Alterar detalhes de cada tabela; Deletar itens indesejagos.
- Dashboard para controle de vendas

### Cursos
- O site apresenta o catálogo e direciona o acesso aos cursos para o [Patreon da Prisma MakeUp](https://www.patreon.com/cw/PrismaMakeUp).
